VIPTravelGeorgia Driver Languages

1. Supabase Dashboard > SQL Editor: execute SUPABASE_DRIVER_LANGUAGES.sql once.
2. Upload the 3 JSX files to GitHub preserving their paths:
   app/admin/page.jsx
   components/pages/cars.jsx
   components/VehicleCards.jsx
3. Wait for Vercel deployment.
4. Admin > Cars > Edit: select Driver Languages and save.
5. Check /en/cars and homepage car card > Vehicle details.

Existing cars have no languages selected; language badges are hidden until set.
Only these three components and a new Supabase column are modified.
